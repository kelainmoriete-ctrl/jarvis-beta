# Jarvis Voice Assistant v3

A lightweight Android voice-assistant starter project designed for browser-based building on GitHub Actions.

The app listens after the user presses **Speak**, recognizes Urdu/Hindi-style speech, speaks a response, and can open common services from voice commands.

The GitHub workflow builds a debug APK using JDK 17, Android Gradle Plugin 8.7.3, and Gradle 8.10.2. No local Linux environment or Gradle installation is required.
